# VibePM 0.8.5 — Project-level Excel Workflow

## New

- Every active Project now provides **Import Tasks…**, **Export Project…**, and **Download Template…** actions.
- Project exports contain that Project's active Tasks and Subtasks with stable IDs and complete planning fields.
- Project templates use the current app language and automatically target the current Project, so no Project column is required.
- Import Preview now distinguishes Create, Update, Skip, and Conflict rows for Project imports.

## Safety

- Task IDs already owned by Inbox, Trash, or another Project cannot be overwritten or moved by a Project import.
- Parent Task references are limited to the current Project or the same workbook.
- Parent cycles and self-parenting block import.
- Global workbooks are rejected from the Project-level importer and remain available through Data settings.
- Every confirmed Project import creates a pre-import Recovery Point.

## Quality

- 57 automated tests pass, including six Project-scoped workbook scenarios.
- Localized workbook structure, ZIP integrity, signed app packaging, native save flow, and DMG integrity were verified.
