# VibePM 0.8.1 — Empty Trash

## What changed

- Added **Empty Trash** / **清空废纸篓** to the Trash header.
- Added a destructive confirmation explaining that cleanup cannot be undone.
- Cleanup removes every deleted Project, all Tasks attached to those Projects, and every independently deleted Task batch.
- Active unrelated Projects and Tasks remain unchanged.
- Successful cleanup clears a pending deletion Undo action and refreshes reminders.

## Compatibility

- Requires macOS 14 or later.
- Uses the same backup schema as VibePM 0.8.0.
- The development DMG is ad-hoc signed and is not yet Apple-notarized.
