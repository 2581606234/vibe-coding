# VibePM 0.8.4 — Reliable Export and Update-Safe Import

## What changed

- Excel templates no longer expose Project or Task creation/update timestamps.
- The first Project and Task ID columns are optional for new rows; blank IDs are generated during import.
- Full existing-data exports include stable UUIDs in the first column.
- Reimporting an exported UUID updates the matching record and Import Preview reports it as an update.
- Timestamp-free template updates preserve the original creation time and record a new update time.
- Existing-data and template exports now use a native macOS save panel with atomic file writing.
- Chinese and English template labels and instructions explain the create-versus-update behavior.

## Compatibility

- Previous `project_key` and `task_key` headers remain supported.
- Previous Chinese headers and canonical full-export headers remain supported.
- Human-readable identifiers still support Project and Parent Task relationships.
