# VibePM 0.8.2 — Selection and Trash Timestamp Fixes

## What changed

- Trash rows now display the stored deletion date and time as a stable absolute timestamp instead of a live relative duration.
- Timestamp formatting follows the selected Simplified Chinese or English app locale.
- Clicking the toolbar selection button now immediately selects every currently visible Task.
- Clicking the same toolbar button again exits selection mode and clears the selection.
- Filtering continues to define the visible select-all scope.

## Compatibility

- Requires macOS 14 or later.
- Uses the same data and backup schema as VibePM 0.8.0.
- The development DMG is ad-hoc signed and is not yet Apple-notarized.
