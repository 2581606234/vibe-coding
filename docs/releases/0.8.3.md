# VibePM 0.8.3 — Complete Excel Import Template

## What changed

- The localized import template now opens directly on the Task sheet and places it first in the visible tab order.
- The Task sheet visibly includes every manual creation field: title, description, scheduled date, due date, status, priority, Project, and Parent Task.
- Both sample Tasks contain descriptions and dates, while preserving a working parent/subtask example.
- Status, priority, Project, Parent Task, Project accent, and archive state retain localized drop-down validation.
- The Instructions sheet now explicitly maps the template to manual Task creation.

## Compatibility

- Existing exported workbooks and older templates remain importable.
- Physical worksheet paths remain unchanged; only the template's visible tab order and default selection changed.
- Project-only fields remain on Projects and Task-only fields remain on Tasks.
