# VibePM 0.8.0 — Data Trust and Recovery

## What changed

- Projects, Tasks, and Subtasks now move to a 30-day Trash instead of being deleted immediately.
- Each deletion is tracked as a batch, so Undo and Restore recover the correct hierarchy without reviving unrelated records.
- User writes save explicitly; failures roll back and display a localized error instead of failing silently.
- VibePM creates at most one automatic local Recovery Point per day and retains the newest 14.
- Settings can create, export, and exactly restore JSON Recovery Points.
- Excel import now shows create/update counts before writing and creates a pre-import Recovery Point.
- Excel export excludes Trash while Recovery Points include Trash state.

## Compatibility

- Requires macOS 14 or later.
- Backup schema 2 stores Trash metadata; schema 1 backups remain readable.
- The development DMG is ad-hoc signed and is not yet Apple-notarized.
