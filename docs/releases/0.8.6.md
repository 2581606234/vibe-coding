# VibePM 0.8.6 — Bulk Task Actions

## New

- Select Tasks in Inbox, Today, or any Project view and choose **Edit Selected…**.
- Change Status, Priority, or destination Project in one operation. Fields left at **Keep current** remain untouched.
- Moving a parent Task includes its Subtasks; moving a Subtask alone safely detaches it from a parent left behind.
- The editor previews affected Tasks and additional Subtasks before Apply.

## Safety and quality

- No-op changes are disabled, archived/deleted Projects are unavailable as destinations, and deleted Tasks are excluded.
- Each committed bulk action creates a pre-bulk Recovery Point.
- Saves are atomic through the existing SwiftData save/rollback path.
- 63 automated tests passed, including new bulk action and Recovery Point coverage.
- Chinese and English packaged UI paths were checked.
