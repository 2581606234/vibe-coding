# VibePM 0.8.0 Acceptance Record

## Scope

Acceptance follows `docs/PRD-v0.8-data-trust.md` and GitHub Issue #14.

## Automated verification

- `swift test`: passed twice after UI integration; final run passed on 2026-09-20.
- Core test inventory: 48 tests across 12 suites.
- Covered behaviors: deletion-batch restore, orphan normalization, 30-day expiry, exact snapshot restore, schema-1 compatibility, Recovery Point cadence/retention, Excel create/update preview, localized templates, hierarchy and sorting.

## Distribution verification

- Release build: passed with Swift 6.2 release configuration.
- Ad-hoc code-sign verification: passed for the built app and the app mounted from the DMG.
- DMG checksum verification: passed (`hdiutil verify`).
- DMG SHA-256: `2172c3c5a977075f9d29240895570be264a8db10f0312a4c7527945b65d3df6b`.

## Functional acceptance checklist

- [x] Parent Task deletion includes descendants and restores the hierarchy as one batch (automated).
- [x] Project restore does not revive an older independently deleted Task (automated).
- [x] Orphaned restored Tasks return to Inbox/top level (automated).
- [x] Automatic Recovery Points are limited to one per 24 hours and retain 14 (automated).
- [x] Exact Recovery Point restore removes records outside the snapshot (automated).
- [x] Import Preview distinguishes create and update counts (automated).
- [x] Invalid or cancelled preview performs no model write (decode-before-write design and review).
- [x] Save failures roll back and keep editor content available for retry (code review and compilation).
- [x] Signed application launch and bilingual visual smoke test in an isolated temporary acceptance copy.
- [x] Create Task, move to Trash, observe count and Undo bar, then restore with Undo (UI smoke test).
- [x] Data settings display automatic Recovery Point status and create/export/restore controls (UI smoke test).
- [x] Chinese-to-English runtime switch updates the main window immediately (UI smoke test).
- [x] DMG verifies, mounts read-only, contains an executable validly signed app, and detaches cleanly.

## Known release constraint

This development release is ad-hoc signed. Public distribution still requires an Apple Developer certificate and notarization.
