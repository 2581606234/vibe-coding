# VibePM 0.8.5 Acceptance Record

Status: Passed

## Scope accepted

- Project actions expose **Import Tasks…**, **Export Project…**, and **Download Template…** in List, Board, and Gantt views.
- Project exports contain one Project and only its active Tasks/Subtasks, including stable IDs, hierarchy, planning fields, status, priority, and audit timestamps.
- Localized Project templates omit the Task Project column and system audit fields; imported rows target the selected Project automatically.
- Project Import Preview classifies Create, Update, Skip, and Conflict rows.
- Cross-Project/Inbox IDs, Trash IDs, invalid external Parent Tasks, self-parenting, and parent cycles are blocked before commit.
- Global Data-settings import/export remains separate and compatible; a global workbook cannot accidentally collapse into a single Project.
- Confirmed imports create a pre-import Recovery Point and write atomically.
