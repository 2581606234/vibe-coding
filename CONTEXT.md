# Personal Project Management

VibePM helps one person turn incoming commitments into organized, actionable project work while keeping their data on their Mac.

## Language

**Project**:
A named outcome that groups related Tasks and can be active or archived.
_Avoid_: Workspace, initiative, folder

**Task**:
A concrete unit of work that can be scheduled, prioritized, and completed.
_Avoid_: Work item, ticket, card

**Subtask**:
A Task whose completion contributes to a parent Task.
_Avoid_: Checklist item, child work item

**Inbox**:
The temporary collection for Tasks that have not yet been organized into a Project or schedule.
_Avoid_: Unsorted, backlog

**Today**:
The focused collection of incomplete Tasks scheduled or due on the current calendar day.
_Avoid_: Daily list, agenda

**Board**:
A status-grouped view of Tasks within a Project.
_Avoid_: Kanban, pipeline

**Status**:
The current workflow state of a Task: to do, in progress, or done.
_Avoid_: Stage, column

**Archive**:
A collection of Projects intentionally removed from active planning without deleting their history.
_Avoid_: Trash, deleted projects
